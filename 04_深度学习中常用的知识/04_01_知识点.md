

# 1 **AI / 深度学习中常用的数值精度（数据类型）大全**，包括 **浮点数和整数**


你问的 “数值精度值” 在 AI / 深度学习 中，主要指 不同精度类型能表示的数值范围和精度



**FP16** = 16-bit floating point（半精度浮点数）

|精度类型|位宽|特点|应用场景|
|---|---|---|---|
|**FP32**（单精度）|32|精度高，数值稳定|训练大部分模型、需要高精度计算|
|**FP16**（半精度）|16|精度降低，显存占用减半，计算加速|推理、混合精度训练|
|**BF16**（Brain FP16）|16|指数位和 FP32 一样，尾数精度低|GPU/TPU 混合精度训练，保持数值稳定性|
|**FP64**（双精度）|64|高精度，数值范围大|科学计算、高精度模拟，不常用于深度学习|
|**FP8**（最近研究型）|8|精度低，但速度快，显存占用极小|AI 推理加速、超大模型，部分实验性 GPU 支持|

|精度类型|位宽|特点|应用场景|
|---|---|---|---|
|**INT8**|8|精度低，显存占用小，推理加速明显|模型量化推理、边缘设备部署|
|**INT4**|4|精度更低，占用更少显存|超大模型量化实验，主要用于推理|
|**INT1 / Binary**|1|二值化|极端压缩/加速模型，少见|

|类型|位宽|特点|应用场景|
|---|---|---|---|
|**FP16/FP32 混合精度**|16+32|用 FP16 计算加速，FP32 保留累加器|深度学习训练加速，常用 NVIDIA Apex / PyTorch AMP|
|**TensorFloat-32 (TF32)**|19 (GPU 特定)|类似 FP32 精度，但计算更快|NVIDIA A100 / Hopper GPU 上训练 Transformer|
|**Quantized Float / FP8E4M3**|8|FP8 的一种格式|NVIDIA Hopper / LLM 推理加速实验|


- **训练时常用**：FP32、FP16、BF16、混合精度
    
- **推理加速**：FP16、BF16、INT8、INT4、FP8
    
- **高精度科学计算**：FP64
    
- **超低精度实验/超大模型**：FP8、INT4、Binary


## 1.1 FP16 用 16 位存储一个浮点数，分为三个部分：

|部分|位数|作用|
|---|---|---|
|**符号位 (sign)**|1|表示正负，0 = 正数，1 = 负数|
|**指数位 (exponent)**|5|控制浮点数的数量级（大/小）|
|**尾数位 / 小数部分 (mantissa / fraction)**|10|控制精度，相当于有效数字|


 符号位 (1 bit)
- 决定数的正负
- 例子：
    - 0 → 正数
    - 1 → 负数

 指数位 (5 bits)
- 用来表示数的 **数量级**
- FP16 指数采用 **偏移二进制 (biased)** 表示法
    - 偏移量为 15（即 exponent = 真值 + 15）
- 指数范围：
    - 真值范围：-14 到 +15
    - 对应 FP16 可表示的最大/最小数值

尾数位 / 有效数字 (10 bits)
- 尾数表示 **数的精度**，决定小数部分精确度
- 在 FP16 里：
    - 默认有一个 **隐藏的最高位 1**（normalized number）
    - 实际精度 ≈ 10 位二进制 → 大约 3 个十进制有效数字

- **1 位符号** → 控制正负
    
- **5 位指数** → 控制数值大小（数量级）
    
- **10 位尾数** → 控制精度（有效数字）
    
- FP16 精度比 FP32 低，但占用显存少，适合 AI 推理或混合精度训练




# 1 目标与思路

- **目标**：在统一 LoadGen 框架下，**客观量化**不同国产芯片（如 Ascend、寒武纪 MLU、昆仑、燧原等）与主流国产框架（MindSpore/Paddle 等）在不同**模型规模/类型**（7B/14B/32B/70B，Base/Chat、代码/多语种）的**适配水平**。
    
- **策略**：以 MLPerf Inference 的**流程与合规**为基线（TTFT/TPOT/QPS、Server/Offline/Interactive、TEST06 一致性），叠加国产生态的**部署与易用性**指标。[docs.mlcommons.org](https://docs.mlcommons.org/inference/benchmarks/language/llama2-70b/?utm_source=chatgpt.com)[GitHub](https://github.com/mlcommons/inference/blob/master/compliance/nvidia/TEST06/README.md?utm_source=chatgpt.com)
    

# 2 测试对象

- **硬件**：Ascend（CANN/MindSpore-Lite）、MLU、昆仑、Hygon/海光 GPU、海光/海思 NPU 等。
    
- **框架/后端**：MindSpore、Paddle（PaddleNLP/FastDeploy）、PyTorch+各自编译栈、TensorRT-LLM（如适配国产 GPU）、vLLM（如对接自研加速）。
    
- **模型族**：LLaMA/Llama 2/3、Qwen、Baichuan、DeepSeek、Mixtral（MoE）等；规模 7B–70B，任务涵盖**通用指令**、**中文对话**、**代码**、**推理**。
    
## 2.1 主要指标（统一定义，便于对比）

1. **性能**：
    - **TTFT**（Time‑to‑First‑Token）与 **TPOT**（Time‑per‑Output‑Token），Server/Interactive 关键；
    - 吞吐（QPS / tokens/s），Offline 关键；
    - 资源利用：显存占用、带宽、算子覆盖率、引擎构建时间。[GitHub](https://github.com/mlcommons/inference/blob/master/language/llama2-70b/README.md?utm_source=chatgpt.com)
2. **准确率/一致性**：复用 `evaluate-accuracy.py` 体系，按任务提供对齐的评测集与判分；通过 **TEST06** 做输出一致性校验。[GitHub+1](https://github.com/mlcommons/inference/blob/master/language/llama2-70b/evaluate-accuracy.py?utm_source=chatgpt.com)
    
3. **稳定性**：长稳跑、错误率、OOM 率、冷启动时延。
    
4. **易用性**：部署步骤、文档完善度、容器与权重管理、对 MLPerf/LoadGen 的即插即用程度。
    
5. **能效**（可选）：tokens/J 或 QPS/W。
    

# 3 测试环境

- **软件基线**：统一 Python/容器镜像，固定 Transformers/VLLM/后端版本；提供 `Dockerfile` 与 `mlc-scripts`/CM 一键入口。[docs.mlcommons.org](https://docs.mlcommons.org/inference/benchmarks/language/llama2-70b/?utm_source=chatgpt.com)[GitHub](https://github.com/mlcommons/inference/issues/1747?utm_source=chatgpt.com)
- **硬件矩阵**：单机多卡（≥8 卡 80GB 等价显存）、NVLink/昇腾互联/MLU Link；开启大页、Pinned Memory、NUMA 绑核。
- **数据与模型分发**：内网镜像/本地权重缓存，适配“已有本地权重不重复下载”的路径（已有 issue 诉求）。[GitHub](https://github.com/mlcommons/inference/issues/1747?utm_source=chatgpt.com)
# 4 核心测试技术

- **LoadGen 统一驱动**：SUT 只暴露 `generate(prompts) -> (texts, n_tokens)`；在 Server 场景严格触发 `FirstTokenComplete`。[GitHub](https://github.com/mlcommons/inference/blob/master/language/llama2-70b/README.md?utm_source=chatgpt.com)
- **后端插件化**：每种芯片一个 `BackendRunner`（如 `ascend_runner.py`），支持张量并行、KV-Cache 针对性优化、量化（AWQ/GPTQ/INT4-INT8 混精度）。
- **连续批处理与调度**：为长会话压缩尾部空转；对接 TRT-LLM/vLLM/各厂商 Runtime 的**连续批处理**能力以提升吞吐。[GitHub](https://github.com/mlcommons/inference_results_v4.1/blob/main/closed/NVIDIA/code/llama2-70b/tensorrt/README.md?utm_source=chatgpt.com)[rocm.blogs.amd.com](https://rocm.blogs.amd.com/artificial-intelligence/reproducing-amd-mlperf-inference-submission/README.html?utm_source=chatgpt.com)
- **准确率与合规**：统一 `evaluate-accuracy.py` 接口；产物进入 `results/`，保证 `n_tokens` 与输出一致，过 TEST06。[GitHub+1](https://github.com/mlcommons/inference/blob/master/language/llama2-70b/evaluate-accuracy.py?utm_source=chatgpt.com)

## 4.1 预期测试结果（报告形态）

- **雷达图**：各硬件在 TTFT、TPOT、tokens/s、稳定性、易用性上的综合评分。
- **规模曲线**：7B→70B 的**性能/能效随规模变化曲线**。
- **适配结论**：按**任务类型**（中文对话/代码/推理）推荐硬件+后端组合与“建议 batch/token 上限”。
